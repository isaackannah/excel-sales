# Excel Sales Performance Dashboard

## Project overview
An Excel dashboard analyzing a fictional B2B sales dataset to answer practical commercial questions.

## Dashboard includes
- Total revenue (DKK)
- Estimated profit (DKK)
- Number of orders
- Monthly revenue trend
- Revenue by product category
- Revenue by region
- Revenue by sales representative

## Dataset
- 1,200 fictional order records
- January 2025 to September 2026
- Regions: Nordics, DACH, Benelux, UK & Ireland
- Segments: SMB, Mid-Market, Enterprise
- Categories: Analytics, Security, Automation, Collaboration, CRM

All data is synthetic and created for portfolio practice. It does not represent a real company.

## Files
- `sales_performance_dashboard.xlsx` — dashboard, source data, analysis formulas and project guide
- `sales_data.csv` — source dataset

## Excel skills demonstrated
Excel Tables, structured references, SUMIFS, date-based aggregation, KPI cards, charts and dashboard design.

## Business questions
1. What are total revenue and estimated profit?
2. How does revenue change month to month?
3. Which product categories contribute most revenue?
4. Which regions contribute most revenue?
5. Which sales representatives generate the most revenue?

## CV example
Built an Excel sales dashboard using 1,200 fictional transactions to track revenue, estimated profit and order volume, with monthly trends and breakdowns by category, region and sales representative.

## How to open
Download the workbook and open it in Microsoft Excel. The dashboard is formula-driven and the Sales Data sheet is formatted as a filterable Excel Table.
